# Signal Integrity with LTspice

Two coursework assignments examine transmission-line behavior in the time domain.

- [HW1 — Transmission-Line Reflections](hw1/)
- [HW2 — Termination, Discontinuities, and Stub Effects](hw2/)

Together they cover reflection coefficients, propagation delay, source/load mismatch, source termination, impedance discontinuities, rise-time/electrical-length relationships, and stub-induced ringing.
