## Curation rationale

A portfolio repository should make original technical work easy to audit. Keeping hundreds of duplicated generated files would obscure the student contribution, increase repository size, and risk presenting third-party code as original work. The curated structure therefore favors **original schematics, scenario logic, measured results, and explicit attribution**.
