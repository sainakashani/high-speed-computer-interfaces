# Scenario 5 — Two-Bank Interleaving

Pattern: `WB0L1, WB1L1, RB0L1, RB1L1`.

- Minimum loop: **38 cycles**
- Useful data-bus activity: **16 cycles**
- Efficiency: **42.1052%**
- Approx. throughput: **140.351 MB/s**

Alternating banks overlaps timing recovery in one bank with useful activity in another.
