# Scenario 1 — `WB0L1, RB0L1`

Single-bank write/read baseline with row changes.

- Total loop: **38 cycles**
- Useful data-bus activity: **8 cycles**
- Efficiency: **21.0526%**
- Approx. throughput at `tCK=3 ns`: **70.175 MB/s**

This establishes the cost of activation, recovery, precharge, and minimum row-active timing for a short burst.
